# Türk Masalları Derlemesi Web Sayfası

Türk halk anlatı geleneğinden derlenmiş 10 masalı bir araya getiren web sayfası.
Programlamaya Giriş dersi vize ödevi olarak HTML, CSS ve JavaScript ile hazırlanmıştır.

## Sunum videosu

YouTube: https://youtu.be/jac8dAwPfN8

## Sayfa ne yapıyor?

- 10 Türk masalını listeler; bir masala tıklanınca masal bir pencerede açılır.
- Arama kutusuyla masallar adına göre süzülebilir.
- Masal penceresindeki A− / A+ düğmeleriyle yazı boyutu değiştirilebilir.
- Sayfa bilgisayar ve telefon ekranına uyum sağlar.
- Sayfa internet bağlantısı olmadan çalışır.

## Sayfa nasıl açılır?

1. Depoyu bilgisayarınıza indirin (Code → Download ZIP) ve ZIP dosyasını bir klasöre açın.
2. `index.html` dosyasına çift tıklayın; sayfa tarayıcıda açılır.

Görsellerin görünmesi için `gorseller` klasörü `index.html` ile aynı yerde durmalıdır.

## Klasör yapısı

```
index.html     → web sayfası (CSS ve JavaScript dosyanın içinde)
gorseller/     → sayfada kullanılan görseller
rapor/         → vize raporu (PDF ve LaTeX kaynak dosyaları)
README.md      → bu açıklama dosyası
```
